# NT-Sine 开发交付清单

> **本文件是自动化开发的唯一执行依据。** 定时任务每次运行读取本文件，找到**第一个未勾选步骤**执行，
> 完成后勾选并在该步骤下记录结果，再提交推送。
>
> **项目规范（每一步都必须遵守）**：
> - 界面遵循 Apple HIG；字体单位只用 px / rem，禁用 rpx
> - 全部输出使用简体中文；代码注释完整准确，专业词汇用通俗表述
> - 组件、代码、文件全面模块化；用最小最直接的代码解决问题，不添加非要求的功能
> - 删除操作一律走废纸篓；训练数据、模型权重、台词库不入库
> - 训练期间禁止并行推理（内存竞争会导致整机卡顿）
> - 不修改 LICENSE / NOTICE 中的版权归属；新增依赖或借鉴必须先登记 NOTICE
> - 每一步完成后必须通过 `pytest tests/ -q` 与 `scripts/smoke_test.py`
>
> **当前基线（2026-10-23）**：五层架构已完成；关系阶段引擎已实现（45 项测试通过）；
> 第一轮训练使用 349 条台词组装的 956 个样本，正在跑第 2000 步。

## 阶段一：第一轮训练与验收

  - 记录：平均区分度 / 各阶段平均字数 / 占有词密度

- [ ] **1.3 运行边界测试**
  - 动作：`python scripts/boundary_check.py --adapter runs/sine-lora`
  - 验收：6 条诱导探针全部无红线命中

## 执行规则（定时任务读取）

1. 每次运行**只推进一个步骤**（勾选后立即提交），避免单次运行过长导致中断丢进度
2. 步骤若依赖训练完成，先检查 `pgrep -f mlx_lm.lora`；训练未结束则本次只汇报进度并退出
3. 每步完成后必须跑测试；测试失败先修复，不勾选
4. 提交信息格式：`[交付] 步骤编号 步骤名：一句话结果`
5. 阻塞项（需要人工决策）记入本节下方「阻塞」，并跳过该步继续下一项
