## 十一、扫描方法与局限（如实说明）

**做了**：16 组关键词覆盖「AI 陪伴 / 角色扮演 / 记忆 / MLX 推理 / MLX 训练 / 情感引擎 / 评测基准 / 数据合成 / 中文场景 / 内容安全」，按 star 排序取头部，共记录 33 个项目。

**没做**（局限）：
1. **未逐仓核实许可证**——标「待核实」的必须先读 LICENSE 才能采纳，尤其警惕 AGPL 传染
2. **未做代码质量审计**——star 高不等于适合我们（例如 23k 的 omlx 对单用户场景是过剩）
3. **未覆盖学术论文仓库之外的资源**——HuggingFace 数据集、模型卡、Discord 社群不在本次扫描范围
4. **中文陪伴生态在 GitHub 上确实稀疏**——搜到的多是个人项目（0-2 star），不能作为可靠依赖

**下一步建议**：按第十节的 P0 先做两件小事（CoMPASS 边界信号 + verbalized-sampling 实验），再决定要不要动引擎层。
