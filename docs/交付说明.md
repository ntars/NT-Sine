## 一、这是什么

NT-Sine 是一个**完全离线**的中文情感陪伴对话系统：本地跑一个 4B 参数的中文模型（Qwen3-4B-Instruct-2507 的 4bit 量化版），外面套五层工程机制（世界书、记忆、情感、节奏、过滤），让角色"记得住、不崩人设、说话像人、关系会变"。所有数据留在本机，不联网、不上传。

它由三部分组成：

| 部分 | 是什么 | 在哪 |
|---|---|---|
| 推理与对话服务 | FastAPI 应用 + MLX 本地推理 | `app/` |
| 官网 | 单页静态站点，零外部依赖 | `index.html` + `css/` + `static/` |
| 训练与评测链路 | 数据集构建、LoRA 训练、阶段评测、边界评测 | `scripts/` |

## 二、当前交付状态（务必先读）

本项目按「工程」与「模型质量」两条线分别验收，两条线的进度不同，不能混为一谈。

**工程线：可交付。** 五层机制全部落地并有回归测试守着（201 项回归 + 22 项冒烟全绿）；对话链路、调试接口、记忆落库与召回、关系阶段推进、主动消息冷却、输出过滤均实测可用；官网已上线。

其中「关系阶段推进」在本轮之前其实是不通的——亲密值唯一的写入口没有任何调用方，后三个阶段永远到不了（详见 `README` 第九节第 15 条）。现已补上六类事件识别与主链路调用，实测真实链路里亲密值 20 → 35 → 50 → 65，`/api/state` 也直接给出当前阶段。

**模型质量线：未达标，二轮已验收完毕。** 二轮（3200 步 / 3022 样本）实测：四探针 × 五阶段的平均区分度 **2.25/5**（目标 4/5），与首轮 2.25 完全持平；复读占比 40%，只是坍缩句从「……你别把这事说出去。」换成了「……你今天怎么突然这么会说话。」；占有词与冷淡词密度均为 0%。结论是**关系阶段仍停留在提示词层面，没有真正进入权重**。

**「数据量不足」这个首轮归因已被自己的实验否定**：样本从 956 扩到 3022（3.2 倍），区分度一分没动。二轮收尾时做了四组对照实验（`scripts/diagnose_stage.py` 可复现），把真因切到三层：

1. **阶段信号被长 system 稀释**——阶段卡只占系统提示的 12.7%（118/957 字符）。同一句阶段要求追加到这份长 system 末尾、或挪到紧邻用户消息的位置，五阶段输出一字不差；换成三句话的极简 system，输出立刻随阶段变化。模型有听话能力，是 957 字的音量把它盖住了。
2. **LoRA 压平了基座原有的条件响应能力**——同一探针，基座裸模型会分条、有口癖、有动作描写（「喂，傻子，你当我是滤镜吗？／你欠我的，是明天的早餐。」），加 adapter 后只剩一句。
3. **每格台词多样性不足**——「破冰/被夸」128 个样本只有 19 句不同的话（独立率 15%），全库独立率中位数 24%。模型是从 19 句池子里挑，贪心解码必然每次挑到同一句。

**第三轮的四个动作**已写入 `docs/开发交付清单.md` 的 2.30 记录：补台词多样性（25 → 60 条/格且组内零重复）、把阶段信号前移到紧邻用户消息（唯一已被实验验证有效的杠杆）、训练量回到 1000 步附近并把 rank 提到 16、补齐场景 × 阶段矩阵。达到 4/5 之前，对外版本号停在 v3.4。

**这一轮修通了一条关键通路**：记忆抽取原先完全依赖模型输出 JSON，而微调模型连「只输出 JSON」都做不到，导致五轮真实对话后 memories 表恒为 0、且接口看不出异常（「不健忘」这条第一理念实际不通）。已加规则兜底，实测五轮后落库 2 条干净记忆并被 system 正确召回。

**一句话结论**：现在可以拿去跑、拿去用、拿去看代码，但**不要对外宣称"情感表现已经做好"、"关系会变已实现"**——它还没做到。记忆与人格这两条是真的通了，关系阶段这条还差一轮训练。

## 三、运行方式

### 3.1 环境

- macOS（Apple Silicon），Python 3.11+
- 依赖：`pip install -r requirements.txt`（已核对完整，无需额外安装）
- 基座模型：`~/Documents/Github/Sine 大模型/基座模型/Qwen3-4B-Instruct-2507-4bit`（Apache-2.0）
- 微调权重：`models/sine-fused`（由基座 + adapter 融合产出，不入库）

### 3.2 三步跑起来

```bash
# 1. 起本地推理服务（加载融合模型，OpenAI 兼容协议，端口 8081）
bash scripts/serve_mlx.sh models/sine-fused 8081

# 2. 起对话应用（另开一个终端）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8420

# 3. 说一句话
curl -s -X POST http://127.0.0.1:8420/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"我今天好累，加班到十点才下班"}'
```

配置在 `config/settings.yaml`。`ollama.base_url` 填推理服务地址时**不要带 `/v1`**（生成层会自己拼）；`ollama.model` 填融合模型目录，**不要直接挂 adapter**——实测那样会静默退回未微调基座，回复变客服腔。

### 3.3 自检

```bash
python -m pytest tests/ -q        # 201 项回归，不依赖模型
python scripts/smoke_test.py      # 22 项冒烟，不依赖模型
python scripts/e2e_check.py       # 端到端（需要推理服务在跑）
```

### 3.4 官网

线上站点：**<https://ai.ntars.cn/>**（已备案自定义域名，直接 200，**不需要任何令牌**）。

- 绑定关系：`ai.ntars.cn` CNAME → `ai.ntars.cn.pages.dnsoe4.com`，指向 EdgeOne 项目 `nt-sine-site` / `makers-vn4m2tteqspn`；重部署后自定义域名立刻生效（实测部署完即刷新内容）。
- 部署用 `bash scripts/deploy_site.sh`，最后一行会输出一个带 `eo_token` 的 `*.edgeone.cool` 预览地址。**那个令牌会过期（实测隔一天就 401），只作内部预览**，对外分享一律用 `ai.ntars.cn`。

重新部署一律用 `bash scripts/deploy_site.sh`，**不要在项目根直接跑 EdgeOne CLI**——CLI 会整包上传，把 2.1G 模型权重和训练数据一起推上 CDN。脚本用 `git archive` 只导出仓库追踪的文件。

## 四、能力边界

**已做到的**（都有测试或实测记录）：

- 五层世界书按话题激活，1600 token 预算内择优，褒奖/嫉妒/诉苦等场景卡实测命中
- 事实落在 SQLite，按话题召回；窗口按**轮**计（10 轮 = 20 条消息），不再被二次截断
- 情感五维状态机，单轮变化有上限，否定词与程度副词已处理
- 关系五阶段三轴判定（活跃天数 / 亲密 / 信任），逐级推进不越级，天数按自然日去重
- 输出八步过滤：分条下限 8 字、深夜打字变慢 1.6 倍、复读拦截但对刻意重复豁免
- 主动消息 6 小时冷却，未被回应最多补一句就停；她说的话（含主动开口那句）可由 `GET /api/messages?after_id=` 增量取到，界面能真正看见她开口
- 病娇阶段四类红线（自伤 / 限制自由 / 贬低 / 索取隐私）词表检测，首轮 6/6 通过
- 全程离线，无任何网络请求（除本地推理服务）

**还没做到的**：

- 阶段区分度 ≥4/5 —— 首轮 2.25/5、二轮 2.25/5（样本 956 → 3022 后指标一分未动，「数据量不足」这个归因已被自己的实验否掉）
- 回复多样性 —— 复读率 40%，坍缩句只是从「你别把这事说出去」换成「你今天怎么突然这么会说话」
- 语义级情绪理解 —— 现为词典 + 规则，反讽与长段落隐含情绪会漏判
- 模型约 8% 概率返回空内容 —— 已转为兜底句，不产生 500，但回复质量受损

## 五、已知限制与风险

完整清单见 README 第九节（**16 条中 13 条已修**，剩 3 条：模型空返回概率、词典法情绪理解的边界、关系阶段未进权重）。交付层面额外提示三条：

1. **官网公开访问尚未成立**：EdgeOne 默认域名未备案，裸域名返回 401 拦截页，只有带 `eo_token` 能进。绑主人名下已备案域名才算真正公开（阻塞项 B4）。
2. **情感陪伴类产品的伦理边界**：本项目禁止自伤威胁、限制自由、贬低羞辱、索取隐私四类表达，但词表法只能抓显性越界，隐性情绪勒索需人工抽检。
3. **模型能力受基座限制**：4B 4bit 模型在复杂推理、长文本一致性上明显弱于大模型，人设维持依赖工程约束而非模型本身。
